# Home & Online Tutoring Classes Website

A modern, fully animated React.js website for Home & Online Tutoring Classes based in Islamabad, Pakistan.

## Features

- 🎨 **Beautiful Design**: Modern UI matching the original banner design with purple and yellow color scheme
- ✨ **Full Animations**: Smooth animations using Framer Motion throughout the website
- 📱 **Responsive**: Fully responsive design that works on all devices
- 🚀 **Fast Performance**: Built with Vite for optimal performance
- 🎯 **5 Pages**: Home, About, Services, Testimonials, and Contact

## Pages

1. **Home**: Animated hero banner with curved shapes, features section, and call-to-action
2. **About**: Information about the tutoring service, statistics, mission, vision, and values
3. **Services**: Detailed service offerings including Primary, Secondary, O-Level, A-Level, University, and Web Development
4. **Testimonials**: Student testimonials carousel and achievement gallery
5. **Contact**: Contact form and contact information

## Technologies Used

- React 18
- React Router DOM
- Framer Motion (for animations)
- Vite (build tool)
- CSS3 (custom styling)

## Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```

4. Preview production build:
```bash
npm run preview
```
